# Title card test (2026-10-22)

A Streamlit test page (`title_test_page.py`) with four places for the title card on the v5 kitchens, on desktop and
phone: on the painted sign, on a separate board, automatic, and on the sign but centred on phones. Screenshots are
in `screenshots/` (`desk_<n>.png`, `phone_<n>.png`). Claude's pick: layout 4. The team has not chosen yet.

To run it again, copy `title_test_page.py` back to `design/pixel-art/` and run
`python -m streamlit run design/pixel-art/title_test_page.py --server.port 8502`.
