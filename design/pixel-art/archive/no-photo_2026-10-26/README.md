# The "no photo yet" picture (2026-10-26)

How the picture on recipe cards without a photo was chosen. The app uses `../../assets/no_photo_skillet.png`, made
by `../../skillet_from_concept.py` (64 px, shown at 128 px).

| File | What it is |
|---|---|
| `first_pixel_drafts_x6.png`, `no_photo_drafts.py` | The first four pixel drafts; B (spoon and fork over a pan) was picked |
| `first_pixel_pick_B_32.png` | Draft B, 32 px, in the app until the photo replaced it |
| `photo_stocksnap_cc0.png`, `photo_stocksnap_cc0_small.png` | The real photo used next ("Wooden Spatula", Nordwood Themes, StockSnap, CC0 1.0) |
| `stoneware_pixel_64.png`, `no_photo_outlined.py` | Pixel art hand-placed from that photo, one-pixel outlines |
| `skillet_concept_gemini.jpg` | med27-coder's concept art made with Gemini: the photo's idea on a cast-iron skillet |
| `skillet_sizes_48_to_150.png` | The concept as pixel art at 48, 64, 96, 128 and 150 px; 64 px was picked |

The other drafts and comparison sheets were deleted when this folder was made; they are in the git history.
The two scripts here ran from `design/pixel-art/` (they import `make_pixel_art`); copy one back to run it again.
