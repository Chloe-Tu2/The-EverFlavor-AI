# The Team's Concept Kitchens

The four full kitchens the team made (AI-generated concept art, 2026-10-21, 1672 x 941), kept as references.

| File | Kitchen | Notes |
|---|---|---|
| `chinese_original.jpg`, `chinese.jpg` | Chinese ("The Jade Wok") | |
| `mediterranean_original.jpg`, `mediterranean.jpg` | Mediterranean ("The Golden Hearth") | |
| `mexican_original.jpg`, `mexican.jpg` | Mexican ("The Joyful Kitchen") | |
| `middle_eastern_original.jpg`, `middle_eastern.jpg` | Middle Eastern ("The Saffron Market") | |

`*_original.jpg` is the picture as the team made it. The files without `_original` have **the sign's text painted out**
(the letters filled in from the paper around them, with OpenCV's inpainting), because the app writes its own
title, "EverFlavor Kitchen", as a separate element: on a phone the picture is cropped and a title painted on it
would be lost.
